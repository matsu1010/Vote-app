# Vote App Local-First Backend

This project is being built as a local-first Python application using FastAPI and SQLite.

## Structure

- `backend/` - Python backend application
- `data/` - local SQLite database and exported ZIP files
- `README.md` - project overview

## Local-first goal

- No remote server required
- All voting data stored locally on the user's machine
- Users can export data as ZIP/JSON/CSV whenever needed
